About LOZ Live

Map key

LOZ Live is a demo prototype. Landing screen is a simple tiled map (Leaflet + Esri Canvas light/dark gray basemap, matching Sun/Night mode; CARTO Positron/Dark Matter if a CARTO key is set). Pins are venues from venues.csv that have a verified Spyder cam URL. Each pin is the venue's verified street address, geocoded with OpenStreetMap Nominatim (5 Oct 2026). Spyder's published coordinates were 1.7–12.7 km off and are no longer used. Pins that would overlap (for example the three Bagnell Dam Strip venues) are spread apart on screen with a leader line back to the true point. A dashed amber ring means the location is approximate. Not a navigational chart.

Categories. Boat-up (circle, anchor) = dock access, pool / pool parties, or waterfront entertainment. Lake view (rounded square, fork + wave) = restaurant with a lake view, mainly dinner. Off-water (diamond, glass) = bar/restaurant with no lake view found. Each category was assigned only from Spyder cams (dock / poolside / lake-view), the venue's own site, and july3_venue_data.json; the evidence is in venues.csv category_source. Where the evidence was thin the sheet says "Evidence limited" (category_confidence = low). Dock access is not claimed unless a dock cam or the venue says so.

Busyness is sample data, BestTime-style, not live. Each venue gets a deterministic fake weekly forecast shaped like the BestTime.app API (hourly %, peak/quiet/busy/surge hours, dwell time, open hours) plus a fake "live vs usual" value for the current hour. The % maps to the vibe colors: green = space available (<40%), yellow = getting busy (40–69%), red = very busy (70%+); gray = closed in the sample hours. A vibe check overrides the color in this browser session only.

Cams are outbound deep-links to SpyderNetwork. Embeds are blocked (X-Frame-Options: SAMEORIGIN). Menus, events and live music on venue cards are real, each with a source link (checked 19 Oct 2026); busyness is still sample data.

CSV has 23 venues; 18 have verified Spyder cams (18 pins). Homepage index lists 65 cam paths (all opened 5 Oct 2026). Non-nightlife cams (boutiques, radio, shelters, etc.) stay out of the map on purpose.

Nearby vibe check is opt-in (📍 button on the map). Within 50 yards of a venue you get one prompt per visit and can post one vibe check per venue per hour. Limits are kept in this browser only, not per person.

Pool cams filter shows the 5 venues with a Spyder cam tagged poolside (6 cams: Alhonna outdoor + indoor, Backwater Jack's, Dog Days, Encore, Lazy Gators). Pinned venues with a pool cam get a small blue mark. Alhonna Resort & Marina is a resort pool, not a verified bar.
